Lo que necesitas saber

¿Cómo se alcanza el límite de tamaño?

Primero se prueba una calidad alta. Si el archivo supera el límite, se busca una calidad menor. Si eso no basta, se reducen las dimensiones manteniendo la proporción y se repite el proceso. Un límite muy pequeño puede producir una imagen con poco detalle.

¿Qué formato conviene elegir?

JPG suele ser una opción compatible para fotografías y formularios. WebP permite conservar transparencias. Comprueba qué formatos admite la página donde vas a utilizar la imagen.

¿Se conservan animaciones y metadatos?

La salida es una imagen estática: las animaciones no se conservan. La imagen se vuelve a generar con Canvas y no se copian los metadatos originales, como EXIF. No es una herramienta de preservación de perfiles de color ni de edición sin pérdida.

¿Por qué el resultado no pesa exactamente lo indicado?

El valor elegido es un máximo, no un tamaño exacto. El peso depende del contenido, las dimensiones y el codificador del navegador. No se añade relleno para aumentar artificialmente el archivo.
